Временный просмотр PUB

Проверка анонимной временной сессии. Регистрация и постоянное сохранение не нужны.

Пока только просмотр. Редактирование и скачивание изменённого файла не поддерживаются в этом режиме. Оригинальный PUB не изменяется.

Открыть файл

Выберите PUB. Данные временной сессии не добавляются в постоянные проекты.

Вкладка хранит приватный ключ сессии только для восстановления просмотра. «Забыть» очищает ключ в этой вкладке, но не удаляет файл с сервера досрочно. Сервер блокирует доступ по истечении TTL и удаляет временные данные.
