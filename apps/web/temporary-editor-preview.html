Временный редактор PUB

Проверка анонимной временной сессии. Регистрация и постоянное сохранение не нужны.

Просмотр и PDF без правки. Откройте поддерживаемый PUB и скачайте PDF с отчётом об ограничениях точности. Также можно перемещать поддерживаемые фигуры (после выбора — стрелками клавиатуры по 1 пункту), изменять их размер и редактировать простой текст рамок, затем скачивать изменённые PDF, IDML или ODG. Сохранение изменённого .pub не обещается. Исходный PUB неизменен.

Открыть файл

Выберите PUB. Данные временной сессии не добавляются в постоянные проекты.

Вкладка хранит приватный ключ временной сессии. «Забыть» удаляет только локальный ключ. «Удалить временную сессию с сервера» немедленно отзывает доступ и очищает временные файлы после подтверждения. Иначе сервер удаляет данные через час после последней принятой правки.

Изменить текст

Поддерживается простой текст одной несвязанной рамки. Существующие окончания строк сохраняются; новые абзацы и сложное оформление не поддерживаются. Все изменения подтверждает сервер.

Страницы

Печатный лист А4 — девять визиток

Предпросмотр формируется из проверенного PDF текущей редакции. После правки документ проверяется заново.

Если встроенный PDF не отображается, скачайте файл и откройте его в программе для просмотра PDF.
