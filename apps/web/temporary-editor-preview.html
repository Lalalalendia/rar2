Временный редактор PUB

Работа с документом · временная сессия
Возможности и ограничения

Проверка анонимной временной сессии. Регистрация и постоянное сохранение не нужны.

Просмотр и PDF без правки. Откройте поддерживаемый PUB и скачайте PDF с отчётом об ограничениях точности. Можно перемещать поддерживаемые объекты (после выбора — стрелками по 1 пункту), менять размер, редактировать простой текст и создавать прямоугольники. Изменённые PDF, IDML или ODG доступны после подтверждённой правки. Порядок наложения новых объектов может быть частичным. Сохранение изменённого .pub не обещается; исходный PUB неизменен.

Открыть файл

Исходный PUB не изменяется. Сохранение обратно в .pub пока недоступно.

Выберите PUB. Данные временной сессии не добавляются в постоянные проекты.

Хранение и удаление данных

Вкладка хранит приватный ключ временной сессии. «Забыть» удаляет только локальный ключ. «Удалить временную сессию с сервера» немедленно отзывает доступ и очищает временные файлы после подтверждения. Иначе сервер удаляет данные через час после последней принятой правки.

Изменить текст

Ограничения редактирования текста

Поддерживается простой текст одной несвязанной рамки. Существующие окончания строк сохраняются; новые абзацы и сложное оформление не поддерживаются. Все изменения подтверждает сервер.
