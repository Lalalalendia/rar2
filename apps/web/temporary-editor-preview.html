Временный редактор PUB

Проверка анонимной временной сессии. Регистрация и постоянное сохранение не нужны.

Правка поддерживаемых объектов. Временная сессия допускает перенос поддерживаемых фигур и выгрузку изменённого IDML или ODG. Сохранение изменённого .pub не обещается. Исходный PUB неизменен.

Открыть файл

Выберите PUB. Данные временной сессии не добавляются в постоянные проекты.

Вкладка хранит приватный ключ временной сессии. «Забыть» удаляет только локальный ключ, не серверный файл. Сервер удаляет временные данные через час после последней принятой правки.
